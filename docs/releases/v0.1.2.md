# DS Bot v0.1.2

## 中文

本版发布 main 已合并的插件更新、群聊权限与实时进度改进；不包含尚在审查的移动端分屏/阅读位置 PR #2 或 Hermes worker PR #3。

### 主要变化

- 同步上游 v0.1.6，保留本分支的手机连接、IPv6 和安装流程。
- 桌面与手机增加独立的插件更新页面和修复安装入口；固定提交安装可检查新版本，升级继续使用经过校验的不可变源码。并发检查、安装失败恢复及更新回执更可靠。
- 桌面与手机支持群级权限预设。所有成员 Session 应用成功后才保存群设置；失败明确报错并允许重试，不再把未完全生效的权限限制显示为成功。
- 手机展示群任务实时进度、当前任务和成员状态；通过稳定回复标识关联实时进度与正式消息，避免 JSON 格式差异造成重复回复。
- 改善 Bot 转发/群聊链路限制、停止控制和工具行为，并提供明确的 IPv6 开关与地址选择。

### 安装与更新

请一起更新主机插件和手机 App。安装或重装插件，在 DSH **插件 → 添加插件** 粘贴下面一整行，启用后按提示重启 DSH：

```text
github:QingJ01/DS-Bot-App#e74c391af76b3a50252e244bea8dc470528a5b4c&path:ds-bot
```

此提交包含本版的插件源码；发布标签只追加本说明，不改变插件包内容。现有插件也可通过插件更新页面检查并安装新版本。不要删除用户数据或关闭 pnpm 完整性校验。

| 文件 | 用途 |
| --- | --- |
| `ds-bot-0.1.2.tgz` | DSH 插件归档；常规安装优先使用上面的固定提交文本 |
| `dsbot-android-arm64-v0.1.2.apk` | Android ARM64 手机 |
| `dsbot-android-x86_64-v0.1.2.apk` | Android x86_64 模拟器 |
| `SHA256SUMS` | 本版插件、APK 和公开证书校验和 |
| `DeepSeekBot.cer` | Android 签名公开证书 |

Android 沿用正式版签名，versionCode 由发布流水线递增；不需要卸载正式旧版。安装插件后按提示重启，主机 Bot 与聊天数据保留。iOS 本次不提供安装包。原 v0.1.0、v0.1.1 及其修订标签和下载文件保持不变。

下载文件后，在同一目录运行 `sha256sum -c SHA256SUMS`（macOS 使用 `shasum -a 256 -c SHA256SUMS`）。发布流水线必须通过版本一致性、插件/App/SDK 测试、类型检查和 APK 签名校验才会发布。本版没有新增真机或真实模型验收结论。

## English

This release packages changes already merged into main: upstream v0.1.6 integration, immutable plugin updates and repair installation, group permission presets, mobile live group progress, and IPv6 address selection. It does **not** include the pending mobile navigation/split-view PR #2 or Hermes worker PR #3.

Group permission changes are saved only after every member Session accepts them; failures are surfaced and partial changes can be retried. Mobile live and durable group replies now share a stable identity, preventing duplicate replies caused by JSON formatting differences. Update checks preserve full-commit installation sources and improve concurrent checks, failure recovery and update receipts.

Update both the host plugin and Android App. For plugin installation or reinstallation, paste the full GitHub specification above into **DSH → Plugins → Add plugin**, enable it, and restart DSH when prompted. The pinned commit contains the released plugin files; the release tag only adds these notes. Existing installations can also use the plugin update page. Do not disable pnpm integrity verification or delete user data.

Use `dsbot-android-arm64-v0.1.2.apk` for phones or `dsbot-android-x86_64-v0.1.2.apk` for emulators. The existing production signing identity is retained and the workflow increments Android versionCode. Host conversations remain intact; no iOS binary is provided. Verify all downloads against `SHA256SUMS`. Previous release tags and assets remain unchanged.

Publication is gated on coordinated versions, plugin/App/SDK checks, TypeScript and APK signing verification. No new physical-device or live-model acceptance testing is claimed for this release.
