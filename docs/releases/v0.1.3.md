# DS Bot v0.1.3

## 中文

插件、Android App 和新增的独立 Windows/macOS 桌面 App 同步升级到 0.1.3。本次包含上游 v0.1.7 及冻结 dev 提交 `a5bba4d4ce0c08d1a1965ca89df652c9220275ef` 的更新，并保留 fork 的手机桥接、安全、安装与发布逻辑。

### 主要变化

- 独立桌面端：自带固定版本 DSH、独立数据和工作目录，首次启动可复制已有团队。手机授权、HTTPS/TLS 身份不随团队复制；目标手机入口默认关闭，需重新配对，原主机不变，用户编写的手机技能保留。
- 服务商/模型管理、Bot 交接等待状态及结果回传、群附件、超长消息文件化和多窗口一致性改进。
- 修复权限部分生效却报成功、同名能力静默覆盖、每设备 WebSocket 并发配额和折叠侧栏裁剪。
- 换段不再复制/删除定时任务；任务保留原 Session，到期提醒唤醒当前段。不自动清理旧版本已经产生的重复任务。
- Docker 缓存依赖与策略元数据，离线重装失败时恢复旧 profile；保留完整性校验。
- 修复启动时团队列表先于会话目录到达导致的 unknown-session 错误。
- 修复桌面导入遗漏群主会话导致群聊打不开的问题；手机离线、重连和失权提示固定显示在聊天导航下方，不随历史滚动被裁切。

### 安装及安全边界

常规插件安装请使用仓库首页记录的完整提交固定安装文本；不要关闭 pnpm 完整性检查，也不要直接重试旧 tarball 安装失败弹窗。请一起更新插件与手机 App。

| 文件 | 用途 |
| --- | --- |
| `ds-bot-0.1.3.tgz` | 插件归档 |
| `dsbot-android-arm64-v0.1.3.apk` | Android ARM64 手机，沿用原签名 |
| `dsbot-android-x86_64-v0.1.3.apk` | Android x86_64 模拟器 |
| `DS-Bot-App-0.1.3-win-x64.exe` | Windows 当前用户安装包 |
| `DS-Bot-App-0.1.3-mac-arm64.dmg` / `DS-Bot-App-0.1.3-mac-x64.dmg` | Apple 芯片 / Intel Mac |
| `SHA256SUMS` / `DeepSeekBot.cer` | 校验和 / Android 公共签名证书 |

下载后执行 `sha256sum -c SHA256SUMS`（macOS：`shasum -a 256 -c SHA256SUMS`）。Windows 安装包没有开发者代码签名；macOS 仅 ad-hoc 签名，没有 Apple 公证。确认来源和校验和后按系统官方提示打开，不关闭系统安全保护。Windows 支持应用内更新；macOS 提示下载新 DMG。没有 iOS 安装包。

手机端尚未补齐完整服务商/模型设置、当前对话运行统计、持久阅读位置和跨设备表情同步。虚拟机、CI 与真实设备的验收范围会单独记录，不能把构建成功当作所有功能验收通过。所有旧标签和下载文件保持不变。

### 已知问题

- P3：撤销设备访问后，会话列表横幅可能与悬浮导航重叠；设置入口仍可用。ChatScreen 中的访问提示固定在聊天导航下方。

## English

The plugin, Android app and new standalone Windows/macOS app ship together as 0.1.3. This includes upstream v0.1.7 and frozen dev commit `a5bba4d4ce0c08d1a1965ca89df652c9220275ef`, preserving this fork's mobile bridge, security and immutable installation/release behavior.

### Highlights

- Standalone desktop app with pinned DSH, separate data/workspace and first-run team import. Import never inherits phone authorization or HTTPS/TLS identity: mobile starts disabled and needs fresh pairing. Source data and authored mobile skills are preserved.
- Provider/model management, hand-off waiting/results, group attachments, long messages as files and multi-window consistency improvements.
- Fix partial permission success, duplicate capability overwrite, concurrent per-device WebSocket quotas and collapsed sidebar clipping.
- Scheduled tasks stay bound to their original Session; due reminders wake the current part without copying/deleting tasks. Existing duplicates from old versions are not automatically removed.
- Cache Docker dependencies/policy metadata and restore the old profile on failed offline reinstalls without weakening integrity checks.
- Fix navigation when the team roster arrives before the Harness session catalog.
- Include each group's own conversation Session in desktop imports. Keep mobile connection/access notices below the chat navigation, outside scrolling history.

Use the full-commit installation text in the repository README for the plugin; update plugin and mobile together. Never disable pnpm integrity checks or simply retry the old failed tarball dialog. Asset names and checksums are listed above. Android keeps its existing signing identity. Windows installs per user and supports in-app updates; macOS offers a new DMG download. Windows has no developer code signature; macOS is ad-hoc signed, not notarized. Verify provenance/checksums and follow the operating system's official opening flow without disabling security. No iOS package is published.

Full mobile provider/model setup, current-part runtime statistics, persistent reading position and cross-device reactions remain separate feature gaps. VM/CI/device acceptance is recorded separately; a successful build does not mean every feature passed. Historical tags/assets remain unchanged.

### Known issue

- P3: After device access is revoked, the conversation-list banner may overlap the floating navigation; Settings remains available. The ChatScreen access notice stays fixed below chat navigation.
