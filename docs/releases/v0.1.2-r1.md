# DS Bot v0.1.2 · 修订 1 / Revision 1

## 中文

**原始 0.1.2 包已撤回推荐使用，请改用本页带 `r1` 的插件和 APK。** 原包遗漏“插件更新”导航图标，触发 React 渲染错误，使整个 DS Bot 设置窗口无法打开。此修订补齐图标并增加真实 React 渲染回归测试；DSH 自身的设置和插件管理不受该问题影响。

### 安装与更新

在 DSH **插件 → 添加插件** 粘贴下面完整文本，启用并按提示重启 DSH。设置窗口打不开时，请使用 DSH 自身的插件管理入口，而不是 DS Bot 设置：

```text
github:QingJ01/DS-Bot-App#2495b96a52836090a5bb458d4fcd40b22d8a9ac8&path:ds-bot
```

已有 `0.1.2` 用户也必须使用这个新固定提交更新；同版本 `r1` 不保证自动升级提示。不要继续使用原始 `e74c391…` 安装文本，也不要只点击旧失败弹窗的重试。不删除聊天数据、lockfile 或缓存，不关闭 pnpm 完整性检查。

| 文件 | 用途 |
| --- | --- |
| `ds-bot-0.1.2-r1.tgz` | 修复后的插件归档；常规安装优先使用上面的固定提交 |
| `dsbot-android-arm64-v0.1.2-r1.apk` | Android ARM64 手机 |
| `dsbot-android-x86_64-v0.1.2-r1.apk` | Android x86_64 模拟器 |
| `SHA256SUMS-r1` | 本修订校验和 |
| `DeepSeekBot.cer` | 沿用的 Android 签名公开证书 |

请一起更新插件与 App。显示版本仍为 `0.1.2`，APK versionCode 递增、签名不变。下载后运行 `sha256sum -c SHA256SUMS-r1`（macOS：`shasum -a 256 -c SHA256SUMS-r1`）。

修订源码使用唯一标签 `v0.1.2-r1`。不带 `r1` 的旧附件仅为兼容现有 pnpm 锁文件而保留，不再推荐安装；原 `v0.1.2` 标签及所有历史下载保持字节不变，不能通过覆盖旧包修复。此修订不包含 PR #2、#3。

**The original 0.1.2 package is withdrawn from recommended use. Install only the `r1` plugin and APKs listed above.** A missing Plugin updates navigation icon caused React to reject the settings tree, preventing every DS Bot settings page from opening. Revision 1 supplies the icon and adds real React rendering regression tests. DSH's own settings and plugin management are unaffected.

Paste the full immutable GitHub specification above into **DSH → Plugins → Add plugin**, enable and restart when prompted. Use DSH's own plugin management while the broken DS Bot settings dialog is inaccessible. Existing 0.1.2 users must also install this new pinned revision: a same-version repair is not guaranteed to produce an automatic upgrade offer. Do not reuse the old `e74c391…` pin, disable integrity checks or delete user data, lockfiles or caches.

Update both plugin and App using the matching `r1` assets. The displayed version remains 0.1.2; Android versionCode increases and the signing identity is retained. Verify downloads with `SHA256SUMS-r1`.

The unique source tag is `v0.1.2-r1`. Original attachments remain available only to preserve existing lockfile integrity; they are no longer recommended. No historical tag or asset is overwritten. PRs #2 and #3 remain excluded.

Real React navigation/page tests pass and fail when the fix is removed. All 708 plugin tests, generated-client consistency and lint pass. A recorded isolated official DSH Web 0.2.0-rc.2 run covered all 12 settings pages, the Bot form, update checks, close/reopen, theme persistence and host-settings navigation without captured runtime errors. Group editing was not exercised because the bench had no group. Publication is gated on App/SDK checks, TypeScript and signed Android builds. No native Desktop, physical Android or iOS acceptance claim is made.
