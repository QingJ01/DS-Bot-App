# DS Bot v0.1.4

## 中文

插件、Android 和独立桌面 App 同步升级到 0.1.4，包含此前已合入的上游 dev（含 v0.2.2）更新和手机适配。

### 主要变化

- 新对话段和首次群成员会话必须成功应用权限预设后才注册、接收工作。失败时保留原会话与输入，未使用的新会话会尝试归档；权限服务不可用时不忽略已有的限制。
- 权限变更与新会话注册串行处理，避免收紧群权限时并发创建的会话遗留旧权限。
- 桌面导入把团队状态写成独立文件，即使源状态是符号链接也不会修改原文件；拒绝符号链接形式的 Bot 根目录。
- 手机原生支持选择、确认、表单卡片和独立 `/side` 侧边对话。历史卡片只读，图表显示数据表，HTML 只显示安全摘要，不执行模型脚本；旧手机客户端明确拒绝 `/side`，不再静默进入主会话。
- 已合入的上游功能包括独立 Bot 浏览器及授权控制、重启后的交接恢复、图表和公式卡片，以及 Linux 桌面打包。

### 安装与边界

请一起更新插件和 App。插件使用本版本最终源提交的完整 SHA 安装：`github:QingJ01/DS-Bot-App#<40-character-source-commit>&path:ds-bot`；发布时提供可直接复制的固定提交文本，不使用可移动分支。

Android 沿用既有签名，保留应用数据进行原位升级；下载后用 `SHA256SUMS` 校验文件。所有历史标签和下载文件保持不变，不关闭安装完整性校验。Windows/macOS 签名及系统安全限制与之前版本相同；没有 iOS 安装包。

已知问题：设备失权或离线时，会话列表提示可能与悬浮导航重叠。手机的完整服务商配置、浏览器接管与站点授权管理等仍有功能缺口。自动化、虚拟机界面、正式安装包与实体设备验收分开记录，构建通过不代表所有场景均已验收。

## English

The plugin, Android app and standalone desktop app advance together to 0.1.4, including previously merged upstream dev updates through v0.2.2 and mobile adaptations.

### Highlights

- Fresh conversation parts and first group-member Sessions must successfully apply their permission preset before registration and delivery. Failure preserves the previous Session/input and attempts to archive the unused Session. An unavailable permission service no longer silently discards a configured restriction.
- Serialize permission changes with Session registration so concurrent creation cannot retain an older group preset after a successful restriction change.
- Desktop import materializes team state as an independent file, even when the source state is a symlink. A symlinked Bot root directory is rejected.
- Native mobile options, confirmations, forms and isolated `/side` chats. Historical cards are read-only; charts use data tables and HTML uses safe summaries without executing model scripts. Older clients explicitly reject `/side` instead of sending it to the main conversation.
- Previously merged upstream changes include per-Bot browsers and authorization, handoff recovery after restart, charts/formulas and Linux desktop packages.

### Installation and limits

Update the plugin and app together. Install the plugin using this release's full source commit: `github:QingJ01/DS-Bot-App#<40-character-source-commit>&path:ds-bot`. Publication supplies the concrete immutable pin; do not substitute a moving branch.

Android retains its signing identity for in-place upgrades with data preserved. Verify downloaded files against `SHA256SUMS`. Historical tags/assets remain unchanged; never disable installation integrity checks. Windows/macOS signing and platform security limitations remain unchanged. No iOS package is published.

Known issue: access-loss/offline notices in the conversation list can overlap floating navigation. Full mobile provider configuration, browser takeover and site authorization management remain feature gaps. Automated checks, VM interactions, signed packages and physical-device acceptance are recorded separately; a successful build is not full acceptance.
