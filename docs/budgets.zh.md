# 每日预算

可以为每个 Bot 设定一天的额度。额度用完后，它在次日之前不再接受新工作：发给它的消息会被拒绝并说明原因，其他 Bot 也无法把任务交给它，群聊中原本会轮到它的发言也会在开始前停止。

预算是 DS Bot 既有上限的补充：每条链最多 6 跳、无人监督最多 40 条消息，限制的是 Bot 独自走**多远**；预算限制的是它在这个过程中**花多少**。

## 统计什么

**统计 token，不统计金额。** DS Bot 的用量账本记录每次模型调用消耗的 token（输入、缓存读取、缓存写入、输出），但它并不知道 token 的价格——部署使用哪些模型、价格如何，属于 DeepSeek Harness 与提供商。因此预算是 token 数量，展示页也写作 token。

这个数字与 **设置 → 用量** 页面的口径一致：来自会话日志的推算（预算启用之前的调用同样计入），加上那些不留日志、在流式过程中计量的调用。一个 Bot 的预算覆盖它的全部工作：自己的对话、群聊中的会话、更早的分段，以及在其下派生或分叉的会话。

**“一天”指用户所在时区的一天。** 手机和浏览器在每次读取团队时都会带上时区，团队文件保存最近一次收到的值，因此“今天”以你的午夜为界，而不是主机的 UTC 午夜。

## 设置

```sh
# 每个 Bot 今天可用多少、已用多少、是否已停止
curl -s localhost:PORT/api/bot -H 'content-type: application/json' \
  -d '{"endpoint":"budgets","payload":{"timeZone":"Asia/Riyadh"}}'

# 为某个 Bot 设置每天 250,000 token
curl -s localhost:PORT/api/bot -H 'content-type: application/json' \
  -d '{"endpoint":"budget-set","payload":{"id":"BOT_ID","tokens":250000}}'

# 取消预算
curl -s localhost:PORT/api/bot -H 'content-type: application/json' \
  -d '{"endpoint":"budget-clear","payload":{"id":"BOT_ID"}}'
```

**目前还没有界面**：现在只有上面三个请求，手机桥接会透传它们，以便后续加入界面。Bot 不能设置自己的预算，即使通过另一个 Bot 也不行——只有用户决定 Bot 可以花多少。

## 预算用尽时

- **已在运行的回合会跑完。** 检查发生在工作**开始**之前：把一次模型调用拦腰截断，只会给团队留下一个语义不完整的回复。
- **团队视图会显示。** 设有预算的 Bot 会在团队状态中带上预算，当天用尽后 `blocked: true`，侧边栏与手机无需等待账本扫描即可显示。
- **只记录一次。** 当天第一次被拒绝会写入诊断日志（**设置 → 反馈**，`logs/diagnostics.jsonl`），包含 Bot、预算与已用量；同一天后续的拒绝不会重复记录。
- **次日自动清零**：任意一次检查运行时即开始新的一天，标记随当天首次统计一并清除。

## 需要注意

- **预算是硬性停止。** 用完额度的 Bot 无法回答，依赖它的群聊会停滞，直到你提高预算。请把数值设在正常一天用量之上。
- **统计的新鲜度取决于账本。** 检查会等待用量扫描数秒，然后以账本已有内容作答；恰好在检查之后落地的超大回合，可能超出额度约一个回合的量。
- **它不是安全边界。** 权限预设决定 Bot 可以做什么，预算只决定它可以为此花多少。
