# 手机与折叠屏体验复查

2026-10-15。分支 `fix/mobile-navigation-foldables`。展开后默认左右双栏。

## 本轮改动

- 首页列表和当前对话保留实例。返回列表不再重新挂载、清零滚动位置或额外刷新。
- 宽度达到 760 逻辑像素时显示左侧 300 像素列表、右侧对话。宽度变化不切换组件树。取消竖屏锁定。
- 使用倒序数据的倒置消息列表，让最新消息固定在滚动原点。缓存、完整历史、实时消息依次到达时，不再按估算行高反复找底部。
- 阅读历史时记录消息 ID 和偏移。内容及宽度变化恢复阅读锚点；只有处于最新位置才跟随消息。
- 区分加载中、已加载历史、确实为空。删除进入会话后 350 毫秒强制跳底部的行为。
- 只有尾部新增消息才出现新消息入口。展开正文、加载旧历史、布局变高不再误报。
- 草稿缓存晚到时不覆盖新输入。发送成功只清理未继续编辑的草稿版本。当前界面发送期间禁用输入，后者是竞态防护，未声称复现正常输入路径中的丢字。
- 固定顶部栏增加不透明背景，滚动时不再让消息文字和列表名称穿过按钮。
- 日期分隔使用实际渲染的相邻消息，避免与合并后的思考内容索引错位。

## 验证与限制

浏览器开发预览使用隔离假主机、32 个 Bot、每个 85 条长消息，没有向真实舰队发送测试任务。

- 列表 y=1300 进入对话再返回：节点相同，位置仍为 1300。
- 缓存末尾 6 条与完整 85 条先后到达：最新消息保持在滚动原点。
- 412 → 1000 → 412 像素切换：当前对话节点、草稿保留；按消息锚点恢复，回到原来的 y=1800。
- 阅读历史收到新回复：阅读消息屏幕底边保持在 755 像素；偏移随新增内容从 1200 调整为 1314；出现“↓ 新消息”按钮。
- TypeScript 检查通过；移动端原有 73 个测试及新增 4 个阅读位置测试通过；插件 667 个测试、生成文件检查和 lint 通过，lint 有已有警告。

这些是浏览器测试。Find N5 连接失败，执行器提示未开启无线调试或未连接家中 Wi-Fi。真实折叠、软键盘、系统返回、原生倒置列表及图片加载仍需实机验收。

本轮未替换手机安装版。Android 构建停留在 Gradle 初始化/依赖准备，已停止该任务的构建进程；未生成新 APK。

## 继续值得优化的问题

| 优先级 | 问题 | 依据与建议 |
|---|---|---|
| P1 | 切换 Bot 会丢未发送附件 | 附件仅在 ChatScreen 的本地 state，切换 Bot 会换 key。应按会话保留，并保留所属 session 校验。 |
| P1 | 发送期间不能准备下一条文字 | 输入框在 busy/pending 时禁用。区分正在确认的提交与下一条草稿，补齐恢复和重试路径。 |
| P1 | 搜索范围不清楚 | 首页只搜索名称/角色，正文搜索位于会话选项。明确范围，减少查历史的步骤。 |
| P1 | 后台更新仍可能重排正在浏览的列表 | 已消除返回触发的刷新；实时排序仍在。需要列表可见会话锚点，或回到顶部后再重排。 |
| P2 | Chief 重复入口浪费首屏空间 | 大头像入口和普通条目并存。合并为清楚的主控条目。 |
| P2 | 执行状态不够直观 | 列表主要显示最后一句消息/角色。区分执行中、等用户、失败、完成，并展示接手者、当前步骤和产物。 |
